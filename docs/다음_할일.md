## 🟡 결정이 필요한 것

### 4. `frontend/dist` 커밋 여부 — 배포 시 결정
React 화면은 빌드 결과물(`frontend/dist`)이 있어야 뜨는데 `.gitignore` 대상이다.

- **Node.js 설치 가능한 PC** → 그대로 두기 (`setup.bat`이 자동 빌드)
- **설치 불가한 PC** → `dist`를 저장소에 커밋해야 함 (281KB)

설치 불가인데 그냥 두면 **구형 단일 화면으로 폴백**되어 보고서·검수·실행이력을 못 쓴다.

**같은 Supabase를 보고 있으므로 분류자로 새 작업은 하지 말 것.**
통합본이 충분히 검증되면 아카이브 처리.

### 6. D1 — 회색지대 소스 법무·정보보안 검토
디시인사이드·에펨코리아 수집 방법의 법적 정당성. **기관 검토 대기 중.**
